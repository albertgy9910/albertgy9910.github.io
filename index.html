I am Geyang (Albert) Xu, a Ph.D. student in Computer Science at the University of California, Riverside, advised by Prof. Qian Zhang.

My research is at the intersection of software engineering and AI. I study how AI coding agents evolve, maintain, and modify existing software—especially when past implementation decisions conflict with new task intent. The goal is to make long-horizon, agentic software engineering more reliable: agents should preserve existing functionality, follow the intended design, and keep the resulting code maintainable as repositories change.

I received an M.S. in Computer Science from UC San Diego and a B.S. from the University of Liverpool. At UCSD I worked with Prof. Babak Salimi on stress-testing machine learning pipelines under adversarial data corruption, published in PVLDB / VLDB 2026.

Research Interests

  • Long-horizon agentic software engineering: how coding agents evolve existing repositories, and when they follow repository precedent versus new task intent
  • Testing and reliability of AI systems: systematic evaluation of agentic coding systems as they maintain and modify software
  • Software engineering for machine learning: robustness and reliability of ML pipelines and data workflows

  1. SANER
    Precedent or Intent? What Coding Agents Follow When Evolving Existing Code
    Haichao Zhu, Geyang Xu, Zhaorui Yang, Jiyuan Wang, and Qian Zhang
    2026
    Under review at SANER 2027
    Abs arXiv Bib PDF

    Existing code reveals past implementation decisions but rarely explains the reasoning behind them. When coding agents implement new features or modify existing functionality, past decisions may conflict with new task instructions. This raises a fundamental question for agentic software evolution: when multiple implementations satisfy the same functional requirements, how do coding agents decide whether to follow existing code or new task instructions? We investigate this question through bidirectional, controlled experiments in purpose-built repositories, followed by validation in real-world open-source repositories. Our approach isolates three competing sources of guidance: (1) agents’ default preferences, (2) repository precedents, and (3) explicit task instructions. We conduct 5,625 trials across four coding agents and six implementation pairs, with validation in four open-source repositories spanning three programming languages. We find that agents share the same default implementation choices, yet overwhelmingly follow repository precedent when it conflicts with those defaults (359/360 trials). Crucially, not all precedents carry equal influence: three supporting local files yield 96% adoption, compared with only 4% for sibling-resource files, and changing file placement alone can shift adoption from 0% to 100% at a fixed example count. When new task intent conflicts with existing code, written priority rules achieve substantially higher success than code examples alone. These findings motivate design-decision traceability that preserves not only implementation choices but also the rationale and priorities that should guide future changes.

  2. PVLDB
    Stress-Testing ML Pipelines with Adversarial Data Corruption
    Jiongli Zhu, Geyang Xu, Felipe Lorenzi, Boris Glavic, and Babak Salimi
    Proceedings of the VLDB Endowment, 2025
    Abs arXiv Bib HTML PDF Code

    Structured data-quality issues—such as missing values correlated with demographics, culturally biased labels, or systemic selection biases—routinely degrade the reliability of machine-learning pipelines. Regulators now increasingly demand evidence that high-stakes systems can withstand these realistic, interdependent errors, yet current robustness evaluations typically use random or overly simplistic corruptions, leaving worst-case scenarios unexplored. We introduce SAVAGE, a causally inspired framework that (i) formally models realistic data-quality issues through dependency graphs and flexible corruption templates, and (ii) systematically discovers corruption patterns that maximally degrade a target performance metric. SAVAGE employs a bi-level optimization approach to efficiently identify vulnerable data subpopulations and fine-tune corruption severity, treating the full ML pipeline, including preprocessing and potentially non-differentiable models, as a black box. Extensive experiments across multiple datasets and ML tasks (data cleaning, fairness-aware learning, uncertainty quantification) demonstrate that even a small fraction (around 5%) of structured corruptions identified by SAVAGE severely impacts model performance, far exceeding random or manually crafted errors, and invalidating core assumptions of existing techniques.
